# @screencapture/desktop

Electron desktop application for screencapture.

## Status

This package is a placeholder. Implementation coming soon.

## Planned Features

- Cross-platform Electron app (Windows, macOS, Linux)
- Native window recording capabilities
- Local session storage with electron-store
- Native messaging host for browser extension integration
- Session replay and export
- Integration with @screencapture/core for PII redaction
