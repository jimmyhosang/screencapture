# @screencapture/extension

Chrome/Firefox browser extension for screencapture.

## Status

This package is a placeholder. Implementation coming soon.

## Planned Features

- Chrome Manifest V3 extension
- Content script for DOM recording with rrweb
- Background service worker for session management
- Popup UI for recording controls
- Integration with @screencapture/core for PII redaction
- chrome.storage.local for session persistence
- Native messaging for desktop app integration
